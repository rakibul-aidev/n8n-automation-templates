# n8n Automation Templates

A collection of production-ready n8n workflow templates for common business automation use cases.

## Templates Included

### E-Commerce
- Order fulfillment automation (Shopify → Gmail → Slack → Airtable)
- Abandoned cart recovery workflow
- Inventory alert system

### CRM & Lead Generation
- Lead capture and HubSpot sync
- Automated follow-up email sequences
- LinkedIn lead enrichment pipeline

### AI Integrations
- GPT-4 powered customer support triage
- Claude AI content generation pipeline
- Automated meeting notes summarizer

### Operations
- Invoice generation and tracking
- Team standup aggregator
- Error monitoring and alerting

## Tech Stack

- **Automation:** n8n (self-hosted & cloud)
- **AI:** OpenAI GPT-4, Anthropic Claude
- **Integrations:** Shopify, HubSpot, Gmail, Slack, Notion, Airtable, Google Sheets
